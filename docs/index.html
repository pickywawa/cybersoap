Installation

macOS

Les builds ne sont pas signés. Après avoir copié l'app dans Applications :Builds are not signed. After copying the app to Applications:

xattr -cr /Applications/CyberSoap.app

Windows

L'installeur n'est pas signé : SmartScreen → « Informations complémentaires » → « Exécuter quand même ».The installer is not signed: SmartScreen → "More info" → "Run anyway".

Linux

chmod +x CyberSoap-*.AppImage
./CyberSoap-*.AppImage
